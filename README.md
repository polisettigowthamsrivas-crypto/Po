# Polisetti Gowtham Srivas — Professional Portfolio

Responsive portfolio built with HTML, CSS and JavaScript.

## Open
Open `index.html` in any modern browser.

## Customize before publishing
- Replace `your.email@example.com` with your email.
- Replace GitHub and LinkedIn placeholder URLs with your profiles.
- Add real project repository/demo URLs.
- Optionally add your resume and profile photo.

No build tools required.
